### 도면 입력에 대한 사실

LH 는 **CAD 원본 + PDF(캐드 변환)를 함께** 받는다. "출력본 스캔 금지"가 명시돼 있다.
즉 벡터 도면이 이미 표준화된 형태로 제출되고 있으며, 매도신청 단계 도면 목록에
층별 평면도·주차계획도·오수계획도·방화구획도가 모두 포함된다.

`TECH-SPEC.md` 3.1절의 DWG 처리 방침(사람이 CAD 에서 중간표현으로 내보냄)은 유지하되,
제안서에는 **"입력이 없어서 못 한다"가 아니라 "이미 표준 형태로 존재한다"** 로 쓸 수 있다.

## 폐기된 기획안

`LH_CONVERT_GATE_기획안.md` — 같은 공모전을 겨냥한 **다른 기획안**이다.
ML + 강화학습 + CP-SAT + NSGA-II 를 Phase 0~5 로 쌓는 구성이며, 코드는 작성되지 않았다.

Re:Space 와 충돌하므로 **참고용으로만 보관한다.** 이 문서의 범위·원칙을 이 저장소에 적용하지 않는다.
남긴 이유는 제안서에서 다룰 만한 서술이 일부 있기 때문이다 — 특히 용도변경 전후의 규제 차이,
그리고 "왜 강화학습을 쓰지 않았는가"에 대한 대비 논거.
