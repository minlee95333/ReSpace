### 미결정 ⑨ 종결 — 고를 문제가 아니었다 (2026-08-11)

*"양쪽 돌려보고 고르자"* 했으나, **조문에 답이 박혀 있었다.**

> 건축법 시행령 제34조① — 거실의 각 부분으로부터 **계단(거실로부터 가장 가까운
> 거리에 있는 1개소의 계단을 말한다)** 에 이르는 보행거리가 30미터 이하

괄호 안이 곧 정의다. `min` 이 법정 판정 방식이므로 `all_cores: false` 로 확정했다.

종전 `true` 는 *"보수적인 쪽이 안전하다"* 는 판단이었는데, 이 경우엔 보수적인 것이
아니라 **틀린 것**이었다. 계단을 늘릴수록 불리해져 더 안전한 건물을 벌준다.

| `all_cores` | G4 (계단 1개) | G5 (계단 2개) |
|---|---:|---:|
| `true` (종전) | 124세대 | **95세대** ← 계단을 늘렸는데 나빠진다 |
| `false` (확정) | 124세대 | **152세대** |

스위치 자체는 남겨 둔다 — 발주처가 더 엄격한 내부 기준을 요구하면 데이터만 바꾼다.

**부수 확인**: `highrise_m` 40m 는 조문상 *"층수가 16층 이상인 **공동주택**"* 에만
걸린다. 현재 엔진은 용도를 가리지 않고 40m 를 적용해 오피스텔 등 준주택에는 실제
(50m)보다 엄격하다. 과소 산출 방향이라 안전하며, 미구현으로 남긴다.

### 알려진 한계 (③ corridor)

- 복도 축은 **직선만** 생성한다. 코어가 대각으로 떨어진 경우의 L자 경로는 미구현이며,
  현재는 코어들이 더 벌어진 축 방향으로 직선을 놓는다. G5 작성 시 재검토한다.
- 복도는 평면 **전폭**에 걸쳐 놓인다. 코어 사이 구간만 놓는 방식은 미구현.
- `type == "none"` 이어도 복도는 그려진다. 세대가 0 이 되는 것이지 복도가 없는 것은 아니다.

### 알려진 한계 (⑤ place)

- 유닛 깊이는 복도 수직 방향으로 **고정**이다. 회전 배치는 없다.
- 유닛을 외벽에 붙이므로 복도와 유닛 사이에 띠가 남는다. 그 띠를 통과해 세대로
  진입하는 것으로 보며, 실제 동선 처리(복도 확장·부속실)는 다루지 않는다.
- 기둥 하나가 유닛 폭만큼의 레인을 못 쓰게 만든다 (스윕이 레인 단위로 건너뛴다).
  기둥을 피해 유닛을 어긋나게 놓는 최적화는 하지 않는다 — "규칙 기반 배치"의 대가다.
- 저개입형은 샤프트가 입력돼 있어야 의미가 있다. 없으면 0세대다.

*"용도지역별로 주택이 허용되는가"* 를 엔진이 판정하려 했으나, **판정하지 않기로 했다.**
근거 셋.

1. **LH 공고가 용도지역 조건을 걸지 않는다.** 공고 전문에서 '용도지역'은 한 번
   나오는데 그것도 *"법령에 따라 상업지역 등에 근린생활시설이 필수적으로 포함되어야
   하는 경우"* 로, 매입 요건이 아니다.
2. **국토계획법 시행령 별표의 용도지역별 건축 제한은 조례 위임 부분이 많다.**
   전국 공통 표를 만들면 지자체마다 틀린다.
3. **건축물대장의 지역지구구역 칸이 균질하지 않다.** 실제 표본에서 국토계획법
   용도지역(제3종일반주거지역) 외에 수도권정비계획법 권역(과밀억제권역), 건축법
   지정(가로구역별최고높이제한지역)까지 같은 칸에 섞여 왔다.

대신 **수집해서 판정 근거에 표시한다.** `getBrJijiguInfo` 로 용도지역·지구·구역을
받아 `building.zoning` 에 넣고, 매입제외 항목 `use_change_impossible` 의 '미확인'
사유에 함께 실어 보낸다. 사람이 판단할 재료는 주되 판단을 지어내지 않는다.

에스키스 가산: **상업지역** / 일반미관지구 / 제1종지구단위계획구역.

### 위반건축물 — 이 API 로는 수집할 수 없다 (2026-08-11)

표제부·기본개요·지역지구구역 어느 응답에도 위반건축물 항목이 없다. 세움터에서 대장을
열람하면 표지에 찍혀 있으나 개방 항목이 아니다. `violation` 은 null 로 남고 매입제외
판정에서 '미확인'이 된다 — 건축물대장 등본으로 직접 확인해야 한다.

### 미결정 ⑤ 해소 경위 — 찾던 위치가 틀렸다

*"하수도법 시행령 별표"* 에는 정화조 원단위가 없다. 시행령 **제24조⑤** 가 고시로 위임한다.

```
하수도법 제34조④·제35조②
  → 시행령 제24조⑤  "오수발생량 산정기준은 기후에너지환경부장관이 정하여 고시한다"
  → 기후에너지환경부고시 제2025-165호 별표   용도별 인원산정식
  → 하수도법 시행규칙 [별표 12]              인원 → 유효용량
```

확보한 값:

| 항목 | 값 | 출처 |
|---|---|---|
| 유효용량 | 3인 이하 1.0㎥ / 5인까지 1.5㎥ / 초과분 5인당 0.5㎥ 가산 | 시행규칙 별표12 |
| 공동주택 인원 | `N = 2.7 + (R−2)×0.5`, **1호 1거실이면 2인** | 고시 별표 |
| 숙박시설 | `N = 0.080A` | 고시 별표 |
| 업무시설 / 오피스텔 / 기숙사 | `0.075A` / `0.050A` / `0.038A` | 고시 별표 |

`R` 은 1호당 거실 개수. 각주 1) 이 *"독립된 별도공간으로 침실 기능이 가능하면 거실로 본다"*
로 정의하며 부엌·식당·드레스룸·다용도실은 제외한다.

법령 원문은 [legalize-kr](https://github.com/legalize-kr/legalize-kr) /
[admrule-kr](https://github.com/legalize-kr/admrule-kr) 에서 받았다. 조문 본문은 완전하지만
**별표는 프론트매터에 제목 + law.go.kr 링크만** 있어 수치표는 링크를 따라 받아야 한다.
