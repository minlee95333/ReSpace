# PRD — Re:Space

**비주택 매입 사전판정 시스템**
비주택 주거전환 공급 세대수 산정 및 제약 요인 분석

작성일: 2026-08-07 · 대상: 제17회 LH 국토기술대전

---

## 1. 한 줄 정의

비주택 건물의 기준층 형상과 건물 제원을 입력받아, **평면·주차·정화조 세 축이 각각 만드는
세대수 상한을 계산하고 그중 무엇이 실제 병목인지 가려내는** 매입심의 지원 도구.

> 매입 후 설계하는 것이 아니라, 설계 가능성을 계산한 후 매입한다.

---

## 2. 문제 정의

### 2.1 배경 — LH 비주택 리모델링 매입약정 사업이 지금 돌아가고 있다

| 항목 | 내용 |
|---|---|
| 매입약정방식 공모 | 2026-07-22 발표, 접수 2026-07-27 ~ 09-09 |
| 직접매입방식 | 2026-04-03 첫 공고, 신청물건 검증 절차 진행 중 |
| 올해 목표 | 서울·경기 규제지역 우수 입지 2,000호 우선 공급 |
| 매입 대상 | 건령 30년 이내 + 내진설계 + 주택·준주택 용도변경 가능한 근생·업무·수련·노유자·숙박시설 |
| 착공 목표 | 2027년 상반기 |

공모전 접수 기간과 이 사업의 접수 기간이 겹친다. 심사위원인 LH 직원들이
**지금 이 업무를 실제로 돌리고 있다.**

### 2.2 핵심 문제 — 계량평가로 전환 중인데 한 항목만 정량 수단이 없다

LH 는 매입 심의를 비계량평가 → **서류접수 기반 계량평가**로 전환 중이며,
매입심의위원회를 5명 → 7명으로 확대하고 심의기간 총량제(6개월)를 도입했다.

| 평가 항목 | 정량화 수단 | 상태 |
|---|---|---|
| 임대수요 | 인구·수요 통계 | 있음 |
| 교통·생활편의성 | 접근성 지표 | 있음 |
| 재무영향도 | 재무 모델 | 있음 |
| 가격 적정성 | 감정평가 | 있음 |
| **건축계획 적정성** | **없음 — 사람이 도면을 보고 판단** | **없음** |

**이 항목만 유일하게 정량 수단이 없다.** 그리고 심의위원을 5명에서 7명으로 늘리면,
정량 근거가 없는 상태에서는 공정성이 아니라 **편차**가 커진다.

### 2.3 두 번째 문제 — 판단 대상과 실제 병목이 어긋나 있다

비주택 용도변경 상담의 **70% 이상이 주차와 정화조에서 막힌다.**

- **주차**: 오피스텔은 호당 0.5~0.7대 설계. 주택 전환 시 세대당 1대가 원칙.
  50호에 주차 30대인 건물은 50대를 확보해야 해 사실상 신청 불가.
  단 소형주택 특례로 전용 30㎡ 미만 0.5대, 60㎡ 이하 0.6대.
- **정화조**: 하수도법 시행령상 주택은 오피스텔보다 인당 오수발생량이 크게 잡혀
  같은 호수라도 용량이 부족해진다. 증설·교체 비용 수백만~수천만 원.

현재 심의는 평면 중심으로 판단하는데 실제 병목은 인프라 용량이다.

### 2.4 그래서 핵심 질문이 바뀐다

> **"몇 세대가 들어가나"가 아니라 "무엇이 세대수를 묶고 있나"**

평면·주차·정화조 세 축이 각각 세대수 상한을 만들고,
**그중 가장 낮은 값이 실제 공급 가능량**이다.
어느 축이 병목인지 가려내는 것이 이 시스템의 고유 영역이다.

## 3. 사용자와 적용 시점

### 3.1 주 사용자

LH 매입심의 담당자 및 심의위원.

### 3.2 적용 시점

매입약정 절차 7단계 중 두 곳.

```
서류접수 → 서류심사 → [사전검증] → [매입약정 대상심의] → 매입약정 체결
                          ▲                  ▲
                    부적합 조기 선별    건축계획 적정성 근거
        → 용도변경 리모델링 → LH 매입·공급
```

| 단계 | 값어치 |
|---|---|
| 사전검증 | **시간.** 어차피 부적합할 물건이 대상심의까지 올라가면 위원 7명의 시간을 쓰고, 신청인은 몇 달 기다린 끝에 탈락한다 |
| 대상심의 | **일관성.** 같은 건물을 다른 위원이 보면 다른 점수가 나오는 상태를 정량 근거로 좁힌다 |

## 4. 범위

### 4.1 하는 일

- 다수 신청 건물을 동일 기준으로 분석
- 전환 불가능성이 높은 건물의 조기 선별
- 평면 기준 확보 가능 세대수 산출
- 주차·정화조 기준 세대수 상한 산출
- **세 축 중 병목 판정**
- 배치 불가 구역과 그 사유 표시
- 성격이 다른 전환안 3개 비교
- 판단 근거와 적용 기준 기록

### 4.2 하지 않는 일 (제안서에 명시)

- 최종 구조안전 검토 / 최종 소방검토
- 법적 인허가 승인
- 감정평가를 대신한 매입가격 결정
- 실시설계 및 공사도서 작성
- 전문가 판단을 대체하는 자동승인

**원칙: 안전과 법규는 배점 항목이 아니라 필수 통과조건이다.**

### 4.3 검토 항목 지도

| 영역 | 항목 | 시스템 범위 |
|---|---|---|
| A. 법적 가능성 | 용도지역, 시설군 변경, 건폐율·용적률, 건령, 내진 | 입력받아 사전 필터로만 사용 |
| B. 건축계획 | 채광, 피난거리, 두 방향 피난, 복도 폭, 세대 최소면적, 반자 높이, 차음, 승강기 | **핵심 — 채광·피난·복도·세대면적·반자높이** |
| C. 설비 | 급수·급탕, 오배수 경로, 정화조, 전기 수전, 환기·냉난방 | **정화조 용량 + 배관 근접도(재사용률)** |
| D. 소방 | 스프링클러, 옥내소화전, 자탐, 제연, 방화구획 | 제외 — 후속 전문 검토 |
| E. 구조 | 활하중, 벽체 철거 영향, 외벽 개구부 신설 | 제외 — 후속 전문 검토 |
| F. 부지·외부 | **주차대수**, 조경면적, 대지 안의 공지, 진입로 | **핵심 — 주차대수** |
| G. 사업성 | 입지·임대수요, 가격 적정성, 공사비·공기, 공공성 | 입력값으로 참조 |

## 5. 산출물

| 산출물 | 내용 |
|---|---|
| 전환 가능구역 도면 | 배치된 유닛 + 규정 미달 구역(사유별 색상) |
| 정량 지표 | 확보 세대수, 유형별 구성, 설비 근접도, 세대당 전용면적 |
| **병목 판정** | 평면 / 주차 / 정화조 중 무엇이 상한을 만들었는가 |
| 대안 3안 비교표 | 세대수, 재사용률, 위반 항목, 예상 공사 범위 |
| 미충족 항목 리스트 | 부적합 물건 사전 선별용 |

### 5.1 비용 산출 범위

시스템은 **물량까지만** 낸다. 단가는 사용자 입력이다.

| 시스템이 내는 것 | 사용자가 넣는 것 |
|---|---|
| 확보 세대수, 유형별 구성 | 세대당 내장공사 단가 |
| 철거 벽체 연장(m) | 벽체 철거 단가 |
| 신설 벽체 연장(m) | 경량벽 단가 |
| 설비 재사용률(%) | 배관 신설 단가 |
| 정화조 증설 필요 용량(㎥) | 정화조 단가 |
| 주차 부족 대수 | — |

근거: LH 는 자체 표준품셈·단가 체계를 가진 발주 기관이다. 학생 팀이 만든 도구가
리모델링 단가를 제시하는 것은 정확도 이전에 역할이 맞지 않는다. 발주처가 원하는 것은
"얼마 드느냐"가 아니라 **"무엇을 얼마나 뜯어야 하느냐"**다.

## 6. 화면 구성

| 화면 | 내용 |
|---|---|
| ① 후보 건물 목록 | 건물별 공급량 / 병목 축 / 중대위험 / 판정 |
| ② 건물 상세분석 | 기존 평면, 전환 가능 영역, 채광 부족 영역, 피난경로, 샤프트 거리, 층별 세대수, 필수조건 통과 여부 |
| ③ 대안 비교 | 3개 전환 평면, 세대수, 재사용률, 병목 축, 추천안과 근거 |
| ④ 검토보고서 | 최종 판정, 핵심 수치, 중대 위험요인, 추가 제출자료, 전문가 검토 필요사항, 적용 기준과 기준일, 검토 이력 |

**UI 원칙**: 화면을 열자마자 **"몇 세대 / 무엇이 병목 / 무슨 위험"**이 보여야 한다.
분석 과정이나 점수 그래프는 그다음이다. 총사업비는 단가 입력란과 함께 하단에 둔다.

**필수 문구**: "본 결과는 매입 전 사전검토를 위한 개략분석이며, 구조·소방·인허가
관련 사항은 전문가의 현장조사와 정밀검토가 필요합니다."

### 6.1 판정 등급

| 판정 | 의미 |
|---|---|
| 우선검토 | 공급량·경제성·기간 양호, 치명적 위험 없음 |
| 조건부 검토 | 사업 가능성은 있으나 추가자료·보강 검토 필요 |
| 검토 가능 | 우선순위는 낮지만 특정 조건에서 가능 |
| 부적합 | 필수조건 미충족 또는 개선비용 과도 |

판정에는 반드시 이유가 붙는다.

## 7. 성공 기준

공모전 산출물이므로 성공 기준은 심사 배점에 정렬한다.

| 단계 | 배점 | 이 PRD 의 대응 |
|---|---|---|
| 1차 서면 | 주제 적합성 40 | 2장 — LH 발주처 고유 업무(계획·검토·승인)를 겨냥. 진행 중인 사업과 시기 일치 |
| | 창의성 30 | 2.4 — "무엇이 세대수를 묶고 있나"라는 질문 자체의 전환 |
| | 실현가능성 30 | 5장 — 물량까지만 산출해 단가 근거 질의를 원천 차단. 동작하는 엔진 + 사례 대조 |
| 2차 PT | 창의성 40 | 3축 상한 구조와 병목 전환 시연 |
| | 적용성 20 | 3.2 — 절차 7단계 중 적용 시점 특정 |
| | 경제성·안전성 20 | 사전검증 시간 절감, 4.2 안전 필수통과 원칙 |
| | 파급효과 10 | 심의 일관성, 신청인 예측 가능성, 사전 자가진단 확장 |
| | 준비노력 10 | 선행특허 명시 인용, 사례 대조의 차이와 원인 서술 |

최종점수 = 1차 30점 + 2차 70점.

### 7.1 대표 사례 패키지 (최우선 산출물)

기능을 넓히는 것보다 아래 한 세트를 완성하는 것이 우선이다.

1. 기존 기준층 평면 1개 (에스키스 가산 재구성)
2. 전환 가능 영역 분석도
3. 채광·피난 제약 분석도
4. 공급우선형 / 균형형 / 저개입형 전환 평면
5. 대안별 세대수·재사용률·병목 비교표
6. 시스템 추천안과 근거
7. 3축 상한 비교 화면 (병목 전환 시연)
8. 동일 내용의 HTML 대시보드

이 자료 하나로 제안서, PT, 다이어그램, 시연 화면, 쇼츠 영상을 모두 만든다.

## 8. 차별성 (선행기술 대비)

| 구분 | 빌드톡 특허 (1020250135188) | 본 제안 |
|---|---|---|
| 입력 | 촬영 단말 스캔 | IFC / 도면 좌표 |
| 대상 | 지자체 인허가 검토 | **LH 매입심의 건축계획 적정성** |
| 산출 | 법규 적합 판정 | **공급 세대수 + 병목 축 판정** |

법규 적합 판정은 선점된 것으로 보고 전면에서 내린다.
제안서에 이 특허를 **명시적으로 인용**한다.

선행논문 검색 결과는 사실상 비어 있다(사이언스온: 관련 검색어 전체 1~2건).
신규성 확보에는 유리하나 **인용할 선행연구도 없다**는 뜻이며,
실현가능성 근거를 스스로 만들어야 한다.

공모전 16년 수상작 중 매입 의사결정 각도는 전무하다.
